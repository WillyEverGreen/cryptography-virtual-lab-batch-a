LABORATORY OPERATING HANDBOOK

Welcome to the Cryptography Virtual Laboratory. This platform provides an interactive, hands-on environment for exploring mathematical cryptosystems, cipher mechanics, and cryptographic attack surfaces.

HOW TO COMPLETE AN EXPERIMENT:

  1. Select an Experiment: Choose an active node from the World Map or Catalog.
  2. Review Theory & Procedure: Read the mathematical formulations and operational guidelines.
  3. Interact with the Simulator: Modify keys, alter plaintexts, test block padding, or step through state rounds.
  4. Validate Test Cases: Check your outputs against standard RFC/NIST test vectors.
  5. Complete Concept Quiz: Answer the evaluation questions to clear the sector and earn clearance XP.

ABOUT CRYPTOGRAPHY VIRTUAL LAB

Developed as an integrated college compilation project. Built on the Hub & Cartridge Architecture, enabling multiple independent student groups to build self-contained cryptographic modules that integrate into one seamless platform.

ARCHITECTURAL PILLARS:

  • Zero Collision Sandboxing: Each experiment module executes in its own isolated scope without CSS or global JS pollution.
  • Unified Design System: Clean minimal white & pitch-black dark mode across all modules.
  • Standard 15-Section Contract: Aim, Objectives, Theory, Procedure, Simulation, Analysis, Canonical Vectors, and Quiz.
  • Offline Capable: Completely zero-dependency; functions without external internet connections or CDNs.
