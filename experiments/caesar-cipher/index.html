CAESAR CIPHER & FREQUENCY ANALYSIS

DIFFICULTY: NOVICE

1. AIM

To study, implement, and cryptanalyze the classical monoalphabetic Caesar shift cipher, understand modular arithmetic operations over a finite character ring, and demonstrate vulnerability to brute-force and frequency analysis attacks.

2. OBJECTIVES

  • Implement Caesar encryption using modular addition: C = (P + K) mod 26.
  • Implement Caesar decryption using modular subtraction: P = (C - K) mod 26.
  • Evaluate the size of the key space (K ∈ {1, 2, ..., 25}) and understand exhaustive key search.
  • Visualize English letter frequency distribution and observe the preservation of language patterns.

3. MATHEMATICAL FOUNDATION

The Caesar Cipher is an ancient symmetric substitution cipher historically utilized by Julius Caesar to protect military dispatches. Each plaintext letter is replaced by a letter standing a fixed number of positions down the alphabet.

Encryption Function: E(p) = (p + k) mod 26
Decryption Function: D(c) = (c - k + 26) mod 26
Where: p ∈ [0, 25] is the plaintext letter index, c ∈ [0, 25] is the ciphertext letter index, and k ∈ [1, 25] is the secret shift key.
